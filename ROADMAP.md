# Roadmap

## Fase 1 - Base profesional

- Estructura modular del proyecto.
- Configuracion central con archivo local excluido de Git.
- Conexion PDO preparada.
- Sistema simple de rutas.
- Layout reutilizable con Bootstrap 5.
- Dashboard inicial responsive.
- Esquema SQL, migracion y seed inicial.
- Helpers comunes.
- Carpetas para uploads, exports, logs y temporales.

## Fase 2 - Gestion de plantillas

- CRUD de plantillas.
- Vista previa basica de plantilla.
- Campos configurables por plantilla.
- Validaciones de formularios.

## Fase 3 - Publicaciones

- CRUD de publicaciones.
- Asociacion con plantillas.
- Carga de capturas de pantalla.
- Estados de borrador y listo.

## Fase 4 - Editor visual

- Editor basado en HTML, CSS y JavaScript Vanilla.
- Controles para texto, color, imagen y posicion.
- Vista previa por formato social.

## Fase 5 - Exportacion

- Exportacion PNG.
- Presets para Instagram, Facebook, WhatsApp y LinkedIn.
- Historial de exportaciones.

## Fase 6 - Productividad interna

- Biblioteca de recursos.
- Duplicado de publicaciones.
- Busqueda y filtros.
- Mejoras de seguridad y auditoria.
